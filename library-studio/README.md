# 知页图书馆管理系统

Vue 3 + Vite，实现考核项目1的图书列表、搜索、分类筛选、借阅记录、读者管理、借还书、图书新增编辑与删除。

运行：在本目录打开终端，执行 `npm install`，再执行 `npm run dev`，访问终端显示的地址。

管理员可管理图书和读者。读者身份关联周子涵，可借书并归还自己的借阅。角色切换仅演示前端权限，生产系统需后端认证。

浏览器 localStorage 保存数据；更换浏览器后数据不共享。图片使用 Unsplash 阅读主题配图，需联网访问。概览中的部分统计和动态为展示数据。

构建：`npm run build`。校验：启动网页后运行 `node verify.mjs`（使用本机 Edge）。
